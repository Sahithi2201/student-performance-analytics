## 2. Objective

The objective of this project is to analyze student academic performance using Python, NumPy, and Pandas. The system calculates total marks, average marks, grades, pass/fail results, subject-wise averages, and top-performing students.

## 3. Technologies Used

- Python
- NumPy
- Pandas
- CSV dataset
- Visual Studio Code

## 4. Dataset Description

The dataset contains 20 student records.

The columns are:
- Student_ID
- Name
- Department
- Python
- Maths
- Statistics
- Attendance

The subject marks are used to calculate academic performance.

## 5. Implementation

The program reads the dataset using Pandas.

It calculates total and average marks for each student. NumPy is used for numerical calculations and rounding. Functions assign grades and performance categories. The program also determines pass/fail status, summarizes subject-wise averages, and identifies the top three students.

The analyzed results are saved in `student_performance_report.csv`.

## 6. Key Features

- Reads student data from a CSV file.
- Calculates total marks and average marks.
- Assigns grades.
- Determines pass/fail status.
- Categorizes students as High, Average, or Low performers.
- Calculates subject-wise average marks.
- Identifies the best-performing and lowest-performing subjects.
- Displays the top three students.
- Generates an analyzed CSV report.
